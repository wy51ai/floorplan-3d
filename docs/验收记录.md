# 首版验收记录

## 范围对照

| 首版要求 | 实现与验证证据 |
| --- | --- |
| 真实户型编辑 | 房间多边形、矩形房间生成、墙段绘制、门窗/推拉门属性、层高和完成面记录；浏览器覆盖创建、编辑、撤销、刷新恢复。 |
| 尺寸依据 | 项目、房间、墙体、门窗的来源和复核状态；未知性质墙不能标记拆除；房间和墙体未复核进入检查列表。 |
| 底图校准 | 上传压缩图片，选取两点按已知距离缩放；浏览器验证尺寸改变、底图仍可恢复。 |
| 设备与水电点位 | 生活需求、型号、预留类型、坐标、完成面高度、房间/墙面、回路、设备和控制关联、施工状态。浏览器覆盖添加、生成草稿、编辑和图上定位。 |
| 关联检查 | 缺失预留、缺失高度、失效对象、跨房间关系、墙体偏离、未复核数据；模型及浏览器均覆盖关键情况。 |
| 几何检查 | 旋转家具与墙体、门开启扇区、门窗与墙体重叠；模型测试验证真实洞口与重叠洞口的区别。 |
| 交底导出 | 独立 HTML、浏览器打印入口、点位编号与坐标清单、房间/工种筛选、尺寸来源、验收表；实际预览截图已检查。 |
| 版本与现场问题 | 冻结/查看/恢复版本，保留版本列表；问题责任人、状态、实测记录与照片；浏览器验证。 |
| 完整备份与兼容 | JSON 保存完整户型、底图、设备、点位、照片、版本；旧版补全；非法输入保留当前方案；导入可撤销与重做。 |
| 二维三维一致 | 实际 Chrome WebGL 渲染自定义房间、点位及其高度；在三维中修改点位高度后验证标签投影实时改变。 |
| 原有家具功能 | 家具创建、选择、属性编辑、持久化；新增验证保护避免非法尺寸污染存档。 |
| 手机使用 | 390×844 验证工作区、输入与保存，无页面横向溢出；工具栏收拢，另有「更多工具」。 |

## 补充：户型图自动识别（2026-11-06）

- 入口：「户型 → 上传户型图识别」；预览叠加后再写入项目，可取消且不覆盖当前方案。
- 用户样例图识别约 8 个房间（含厨房、卫生间、客餐厅、阳台、卧室），生成结果通过项目校验；浏览器端到端测试通过。
- 比例优先读尺寸标注合计，也可图上两点 + 已知长度校准；墙体不区分承重性质。
- 依赖：`npm install` 后本地提供 tesseract.js 与 chi_sim 模型；OCR 失败时仍可生成几何，房间名可后改。
