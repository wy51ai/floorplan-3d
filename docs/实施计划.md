# 装修规划首版

依据：用户提供《装修注意点汇总》及本聊天确认的首版方案。目标是让真实户型、设备、预留、查漏、交底使用同一份数据。

## 本次交付与验收
- 可编辑房间轮廓、墙体、门窗和层高；量房来源、复核状态、完成面记录；底图上传、比例校准。
- 设备需求、点位类型、坐标、完成面安装高度、墙面、回路、控制关系、施工备注和状态可编辑。
- 尺寸碰撞、预留缺失、失效关联、未复核尺寸分别显示；不能将参考经验等同于施工规范。
- 按房间/工种生成带编号的图和清单；保存版本、变更说明、检查结果；可打印为 PDF。
- 完整 JSON 备份、导入校验、旧版本迁移、撤销重做、刷新恢复；导入失败不得损坏当前项目。
- 保留既有家具、二维/三维、材料、漫游能力；自定义户型使用共同数据。
- 运行模型测试和浏览器端操作测试，检查桌面/移动布局和实际三维渲染。

## 界面方向
以实际户型为主画面，左侧现有家具库，右侧任务编辑区。顶部按户型、布置、设备点位、检查、交底切换。冷白 #f4f7fa、图纸白 #ffffff、墨蓝 #20394f、工程蓝 #246b9a、提示琥珀 #a16a16、通过绿 #22755d。标题使用系统中文黑体，正文系统 sans，编号和尺寸使用等宽字体。突出图上点位编号与右侧清单的对应，不添加装饰性仪表盘。

## 后续独立阶段
实际智能家居控制接入、可加工柜体下料/孔位、自动布线、多人服务器协作不属于本次首版交付；不以示意图冒充这些能力。
